# Changelog

Все заметные изменения в проекте **OptiCull RAW & Lytro Illum 4D Studio** документируются в этом файле.

Проект придерживается принципов [Semantic Versioning](https://semver.org/lang/ru/).

---

## [0.1.0-alpha.1] — 2026-11-11 (Early-Stage Alpha / Pre-Release)

> ⚠️ **Ранняя стадия разработки (Alpha)**: первый публичный пре-релиз для тестирования архитектуры локального отбора, 4D-рефокусировки Lytro Illum и сквозного логирования.

### Добавлено
- **Ядро Rust + Tauri v2 (`src-tauri/`)**:
  - Многопоточный конвейер пакетного анализа `pipeline.rs` на базе `rayon::par_iter` и `AtomicUsize`.
  - Модуль `engine/ai.rs` для локального нейросетевого скоринга эстетики через ONNX Runtime (`ort`) с поддержкой `Auto`, `CPU`, `DirectML`, `CoreML`, `CUDA` и автоматическим откатом на CPU.
  - Модуль `engine/cv.rs` для оценки резкости через дисперсию оператора Лапласа $3\times3$ и расчета сдвига экспозиции `crs:Exposure2012` относительно 18% Middle Gray.
  - Модуль `engine/lytro.rs` для парсинга пленоптических контейнеров **Lytro RAW (`.LFR` / `.LFP`)** и вычислительных функций **Lytro Illum 4D** (пост-фокусировка $\lambda$, виртуальная диафрагма `f/1.0–f/16`, карта глубины `Depth Map`, сдвиг ракурса субапертур $u, v$ и авто-спасение кадров `4D Refocus Salvage`).
  - Модуль `engine/xmp.rs` для неразрушающей генерации `.xmp` sidecar-файлов в стандарте Adobe Camera Raw с пространством имен `xmlns:lytro`.
- **Система сквозного логирования (`logger.rs` & `logger.service.ts`)**:
  - Кольцевой буфер диагностических событий, запись в лог-файл и интерактивная вкладка «Журнал логов» с фильтрацией по уровням (`DEBUG`, `INFO`, `WARN`, `ERROR`), поиском по стеку ошибок и выгрузкой `.log` файлов.
- **Инфраструктура публичного релиза GitHub (`.github/workflows/`)**:
  - Пайплайн непрерывной проверки `ci.yml` (TypeScript + Vite + Rust `cargo check` на Linux, Windows и macOS).
  - Пайплайн автоматической кроссплатформенной сборки и публикации пре-релизов `release.yml` на базе `tauri-apps/tauri-action@v1`.
